* *Tech*: `Python` · `AsyncIO` · `CDP` · `Pydantic` · `Zero-Trust` · `EGM Architecture`

### 2. [Multimodal RAG Pipeline](https://github.com/ShayanMuhammad-CS/Multimodal_RAG_Pipeline) — Document Intelligence Engine
* **High-Fidelity Document Reasoning**: Fuses dense vector embeddings with Vision-Language Models (VLMs). Inspects charts, schematics, and embedded figures directly rather than lossily guessing from extracted table captions.
* *Tech*: `PyTorch` · `VLMs` · `Vector Retrieval` · `Document AI`

### 3. [DocuMind](https://github.com/ShayanMuhammad-CS/DOCUMIND-RAG-for-Your-Notes) — Zero-Telemetry Local Neural RAG
* **Air-Gapped Private Knowledge Base**: Fully local personal intelligence stack running on consumer hardware via ChromaDB, Ollama, and cross-encoder reranking. Zero tokens or embeddings leave the local network perimeter.
* *Tech*: `LangChain` · `ChromaDB` · `Ollama` · `Cross-Encoders` · `Gradio`

### 4. [MeetSense](https://github.com/ShayanMuhammad-CS/MeetSense) — Modular Audio & Meeting Intelligence
* **Autonomous Meeting Ingest**: Composable pipeline handling audio/video ingest, diarization, speech-to-text, and semantic action item synthesis across high-noise acoustic environments.
* *Tech*: `Python` · `Whisper` · `Speaker Diarization` · `Stream Processing`

### 5. [DeforestAI](https://github.com/ShayanMuhammad-CS/DEFORESTAI-DETECTION-SYSTEM) — Satellite Vision Monitoring
* **Temporal Geospatial Analytics**: Computer vision segmentation network analyzing multi-spectral satellite imagery to detect and track illegal deforestation trends and canopy depletion over time.
* *Tech*: `Computer Vision` · `Satellite Ingestion` · `Segmentation` · `PyTorch`
